### 4、成员注册（群聊）

POST  /user/register

请求体

```
{
  "tenantId": 1001, //前端生成
  "openId": "wx_openid_xxx",  //实际是password，前端注册时将字段命名为openId传给后端
  "username": "alice",

  "identityKey": "BASE64_IDENTITY_KEY",

  "signedPreKeyId": 1,
  "signedPreKeyPublicKey": "BASE64_SIGNED_PREKEY_PUBLIC",
  "signedPreKeyPublicKeySignature": "BASE64_SIGNED_PREKEY_SIGNATURE",

  "preKeyId": 1,
  "preKeyPublicKey": "BASE64_PREKEY_PUBLIC",

  "signingPubKey": "BASE64_SIGNING_PUBLIC_KEY"
}

```
